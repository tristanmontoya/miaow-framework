Construct runtime options with safe defaults.

Parameters:

  • workers – Desired worker count. Values of zero are clamped to one.

  • task_timeout – Timeout used for one simulation task request.

  • job_timeout – Timeout used for whole-job requests.

  • output_root – Root directory for runtime-managed Task output folders. Empty string (default) disables all file output.

  • realization_path – Path to a realization file. Empty string (default) lets realization-driven callers fall back to their own default.

Realization workflows¶

struct RealizationFeature¶

One feature entry from a BMI realization file.

NextGen-style realizations are expanded into one Fortran BMI Task input per catchment. Realization-driven C++ BMI modules are not supported yet.

struct RealizationConfig¶

Parsed BMI realization used to build one Task per feature.

The supported realization format is a NextGen-style global realization with one bmi_fortran module and CsvPerFeature forcing.

Public Functions

explicit RealizationConfig(const std::string &realization_path)¶

Construct a parsed realization from a NextGen-style file.

Relative paths are resolved against the realization file’s parent directory. The parser expands sibling catchments.geojson features into realization feature Tasks.

Parameters:

realization_path – Path to a NextGen-style realization file.

Throws:

  • std::runtime_error – if the realization is malformed or references missing or unusable files.

  • std::filesystem::filesystem_error – if a referenced path cannot be resolved or inspected.
