BMI integration¶

MIAOW’s BMI support targets the Basic Model Interface and the CSDMS BMI C++ interface. Dynamic Fortran plugins use the NOAA-OWP BMI bridge. Realization-driven workflows follow the NextGen realization shape.

class DynamicBmiModel : public bmi::Bmi¶

BMI model backed by a single dynamically loaded C++ or Fortran BMI plugin.

DynamicBmiModel is one model module. It does not own task-level forcing, coupling, output writing, artifact tracking, or execution. Use BmiSimulationUnit<DynamicBmiModel> to construct this model for each task and run it inside a task-level BmiPipeline.

The wrapper exposes the CSDMS BMI C++ interface for the loaded plugin. The BmiModuleConfig selects the dynamic backend and plugin library path. C++ plugins must export bmi_model_create() and bmi_model_destroy(...) unless the module config names different symbols. Fortran plugins must export register_bmi(void**) for the linked NOAA-OWP procedural BMI bridge. If a Fortran plugin exports unregister_bmi(void**), MIAOW calls it after BMI finalization.

class BmiPipeline : public bmi::Bmi¶

Complete task-level BMI pipeline backed by a BmiPipelineConfig.

BmiPipeline owns the BMI lifecycle for one task. It reads a BmiPipelineConfig, constructs configured model modules or receives one model from BmiSimulationUnit, connects forcing to model inputs, writes output, and reports artifacts through the task result.

Use BmiSimulationUnit<BmiPipeline> for realization-derived tasks or other full-pipeline configs. Use BmiSimulationUnit<DynamicBmiModel> for one plugin model that should still run inside this pipeline machinery.

template<class BmiModelType>
class BmiSimulationUnit : public miaow::SimulationUnit¶

Simulation unit that runs BMI models through the task pipeline.

For ordinary BMI model types, including DynamicBmiModel, BmiSimulationUnit constructs a fresh model per task and runs it inside a BmiPipeline. The first task argument must store a serialized BmiPipelineConfig, usually built by make_bmi_model_config(...) and converted with bmi_pipeline_config_to_value(...).

For BmiPipeline, BmiSimulationUnit runs the complete pipeline from the task’s serialized BmiPipelineConfig. This is the path for realization-derived pipelines and subprocess execution.

Template Parameters:

BmiModelType – BMI model type derived from bmi_api::Bmi.
