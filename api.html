enum class miaow::TaskStatus : std::uint8_t¶

Per-task completion status.

Values:

enumerator succeeded¶

Task execution completed successfully.

enumerator failed¶

enum class miaow::ExecutionMode¶

Execution location and process lifetime selected per Task.

Values:

enumerator in_process¶

Execute the task in a parent-process worker actor.

enumerator single_task_subprocess¶

Launch one subprocess for one task and stop it after the result.

enumerator persistent_subprocess¶

Reuse one subprocess owned by a job worker for subprocess-routed tasks.

class Runtime¶

The runtime is model-agnostic and thread-safe. Tasks with unknown SimulationUnitId values fail individually. Persistent subprocess workers are owned by one submitted job.

BMI integration¶

MIAOW’s BMI support targets the Basic Model Interface and the CSDMS BMI C++ interface. Dynamic Fortran plugins use the NOAA-OWP BMI bridge. Realization-driven workflows follow the NextGen realization shape.

BMI pipeline¶

class BmiPipeline : public bmi::Bmi¶

BMI task execution pipeline.

BmiPipeline owns the BMI lifecycle for one Task. It receives a supplied statically typed model through the bmi_api::Bmi interface or constructs a dynamically loaded model from the task configuration. The pipeline currently supports one model component plus the BMI-controlled bmi::ForcingBmi forcing provider. It exposes the configured model’s BMI surface, writes output, and reports artifacts through TaskResult.
