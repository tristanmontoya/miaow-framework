MIAOW: Model-Independent Actor Orchestration Workflows for Scientific Computing¶

Managing concurrent numerical simulation tasks with dynamic workloads and heterogeneous hardware can feel like herding cats. MIAOW embraces that reality by using actor-based asynchronous orchestration so tasks run when they are ready, maximizing utilization across available resources.

MIAOW targets the C++20 standard, uses the C++ Actor Framework (CAF) as its actor orchestration backend, and employs the Basic Model Interface (BMI) for Earth system model integration.

Quick start¶

See the repository README for platform-specific dependency installation. Build the core library and subprocess runner:

cmake -S . -B build -DBUILD_EXAMPLES=OFF
cmake --build build

Build all examples and run the test suite:

cmake -S . -B build -DBUILD_EXAMPLES=ON
cmake --build build
ctest --test-dir build --output-on-failure
